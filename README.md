# Consulta Fácil V2

MVP focado na pergunta: "Já existe uma marca com esse nome?"

Nesta etapa:
- interface de pesquisa de marcas;
- filtros de classe e somente processos ativos;
- backend `/api/marcas`;
- camada de dados separada para podermos conectar a fonte oficial do INPI sem refazer o site;
- resultados de demonstração claramente identificados como demonstração.

A próxima etapa é conectar a fonte real do INPI e substituir os dados de demonstração.
